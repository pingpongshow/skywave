# Skywave v1.0.0 — Release Notes

First production release. All ROADMAP phases (0–7) complete; all
milestone gates M0–M7 met.

## What ships

- HF software audio modem, C++20: 48 kHz real audio ↔ 12 kHz complex
  baseband, three OFDM families (WIDE/MID/NARROW + ULTRA) at 1500 Hz
  center, adaptive mode ladder M0–M14.
- CSS deep tier (M0–M3, SF8–SF5): chirp-spread frames with LDPC r1/2
  soft payload, RAKE tap tracking, handshake-on-CSS — connects and
  moves data at −13 dB SNR (MID, CCIR Moderate).
- VHF-FM band profile (`band=vhf-fm`): 176-carrier family through a
  9 kHz FM channel, modes to 256-QAM r5/6 (M14), measured 25.5 kbps
  net sustained (M7 milestone ≥ 25 kbps).
- ARQ + AMC link engine: HARQ chase/IR, probe-before-promote, carrier
  masking, burst containers, session resume, TX frequency alignment.
- Proto pipeline: zstd compression, coalescing, fragmentation, file
  transfer with resume, broadcast + CW ID.
- Optional: AES-256-GCM link crypto (X25519 + PSK auth), Codec2 voice,
  SDL2/ImGui GUI. TCP data/control/voice ports.
- Link advisor (shadow/assist) for AMC bias, CFO drift counteraction,
  mask threshold tuning.

## Notable fix landed during release testing

The first 2 h soak failed at cycle 79: the M13+ deep-pipe MAC profile
(window 16, 6-codeword containers, batched ACKs) had leaked onto the
HF band profile, stalling small transfers on a lost ACK tail flush.
The profile is now scoped to VHF-FM as a unit; HF M13 keeps window 8,
2-codeword containers, per-burst ACKs (commit 2c622d4). The re-run
soak passed 2587/2587 cycles.
