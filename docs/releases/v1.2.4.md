# Skywave v1.2.4 — Release Notes

A link-layer fix release: NARROW and ULTRA sessions no longer stall in the
two-modem world, and WIDE and MID move more data. The PHY header gains a
`poll` bit, so this changes what goes on the air: Skywave has never been
released, so no compatibility constraint applies, but **both ends of a link
must run v1.2.4**.

## What changed

The faults were in turn-taking timing, which only long frames expose; the
PHY sweeps were healthy throughout.

- **Poll bit.** The ISS sends a window of bursts back to back and marks the
  last one, after which it listens, with a new PHY-header `poll` bit. The
  IRS answers that burst instead of every burst: its per-burst ACKs were
  landing on the ISS's next burst while the ISS was keyed and deaf. The ARQ
  open-loop timeout now covers a whole window, and the IRS's tail flush
  counts silence from the last burst heard. `SKW_NO_POLL` restores
  per-burst feedback for A/B.
- **A capture still airing counts as busy** for the pre-TX gate. The energy
  meter is blind on NARROW (a long burst sits ~4 dB above its own
  min-tracked floor, under the 6 dB threshold) and inside fades.
- **Header-complete decode attempt.** A NARROW robust header is 648 symbols
  (~19.8 s), so a control frame's length was unknowable until its end and
  the next decode rung came ~13 s later. The receiver now tries the moment
  the shortest frame the preamble can start is in hand: the NARROW
  handshake went from 137 s to 86 s.
- **MODE_ACK wait.** After a MODE_CHANGE the ISS holds DATA until the
  MODE_ACK arrives (at most one robust control frame plus 2 s).
- **Idle clock.** A burst whose PHY header decoded refreshes the session's
  idle clock even when its payload failed.
- **Test harness:** `SKW_SOAK_EVENTS=1` makes `soak_st2` print each modem's
  `EVT:`/`MON:` lines with simulated time.

## Results (two-modem world, totals over seeds, vs v1.2.3)

| Scenario | v1.2.3 | v1.2.4 |
|---|---|---|
| Churn NARROW (seeds 11-13) | 0/3 pass (stalls) | 3/3, 66 KB |
| Churn ULTRA (seeds 11-13) | 0/3 pass (stalls at 320 s) | 3/3, 99 KB |
| Churn MID | 113 KB | 145 KB |
| Churn WIDE | 247 KB | 293 KB |
| Floor NARROW 9 dB (seeds 1-6) | 3/6, 12.7 KB | 5/6, 26.0 KB |
| Floor NARROW 6 dB | 0/6, 0 B | 4/6, 16.7 KB |
| Floor ULTRA 9 dB | 4/6, 22 KB | 5/6, 35 KB |
| Floor WIDE 9 dB | 62 KB | 97 KB |
| Floor MID 9 dB | 84 KB | 85 KB |

Single soak seeds swing 0-25 KB on identical code; compare totals.

## Known limitations

- NARROW on the Moderate floor is slow (~4 KB per 10 minutes): each
  one-rung MODE_CHANGE exchange still costs ~45 s.
- Simulation results; on-air confirmation is pending.
- Timing-slip recovery is deferred permanently (owner's decision).
- No LICENSE file (owner's hold).

## Gate results

Cut as a fix release on the owner's instruction: the long gates (TSan,
2-hour soak, conformance sweeps) were not re-run. The conformance sweeps'
PHY is unchanged apart from the new header bit, which is 0 on every frame
they send.
